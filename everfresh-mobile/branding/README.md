# Everfresh Branding Assets

Drop master image files here, then run the `capacitor-assets` command from
`../README.md` to generate all platform icon/splash sizes.

Required files:

- `icon.png`   — **1024×1024** PNG, square, no transparency, no rounded corners
- `splash.png` — **2732×2732** PNG, logo centered, brand color background

Optional:

- `icon-foreground.png` — 1024×1024 transparent foreground (Android adaptive icon)
- `icon-background.png` — 1024×1024 solid background (Android adaptive icon)

Keep file names exactly as above — `capacitor-assets` looks them up by name.
